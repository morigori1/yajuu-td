## v12 カード・セリフ・探索・ハイライト
- 協力/妨害カード：ドラフト後に「次ウェーブの仕込み」を1枚（協力・妨害・賭け/休憩から各1、コスト付き・次ウェーブのみ有効）
- 敵セリフ＋返しバトル：敵が吹き出しでしゃべる。エリート/ボスが挑発→3択で返す（制限時間・スロー）。正解で論破＝周囲スタン＋ダメ＋💰（連続ボーナス）、失敗で敵が勢いづく。PCは1/2/3キー
- 部室ダンジョン探索：3ウェーブごとに部室マップを1部屋ずつ進む（宝箱・謎ロッカー・シャワー室・闇の自販機・先輩の部屋・最上階の部室の主）。隣の列にだけ進める分岐ルート
- ハイライト：ボス撃破・大コンボ・論破・ピンチ・決着を自動キャプチャ。終了画面の「📼 ハイライト」でスライド再生、MVP/仕込み/探索ルートも表示

## v13 手動スキル・塔つぶしAI・壊せる地形/炎上
- 手動スキル（戦闘中、左上バー / Z X C V）：気合ゲージ（時間・撃破で溜まる）消費＋CD
  - 🔥迫真の喝：タップ地点を焼き払い地面を炎上・木箱にもダメ／✋暴れんなよ：全敵拘束／💦汗だく放水：消火＋塔修理＋減速／💪先輩ラッシュ：6秒連射x2
- 塔つぶし後輩（🔨マーク）：W3以降、近くの塔へルートを外れて殴りに来る。塔にHP（Lvで増加、ウェーブ間に回復）、破壊で30%回収。ボスも塔を狙う
- 壊せる地形：木箱・ドラム缶が設置マスを塞ぐ。タップで殴って破壊→💰、たまに迫真スポット出現。ドラム缶は誘爆して範囲ダメ＋延焼
- 炎上マップ：枯れ草・木箱に燃え広がり、道の上の火は敵を焼き、隣の塔も焦がす。焼け跡は燃えない。W4以降ランダム出火、114514砲の火炎床からも延焼
